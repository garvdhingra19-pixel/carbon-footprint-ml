# Carbon Footprint Tracker for ML Models 🌍⚡

A tool to measure, analyze, and report the energy consumption and carbon emissions of training different machine learning models (Logistic Regression vs. Random Forest vs. PyTorch Neural Network).

## Features
- **Climate Impact:** Tracks real-time electricity consumption and CO₂ emissions using CodeCarbon.
- **Model Comparison:** Evaluates traditional ML and deep learning models on identical datasets.
- **Ethics & Transparency:** Answers the trade-off question: *"Is a 1% accuracy gain worth 10x the carbon?"*

## Tech Stack
- **Python**
- **CodeCarbon** (for carbon tracking)
- **Scikit-Learn** & **PyTorch** (for model training)
- **Pandas / Matplotlib** (for analysis and reporting)
